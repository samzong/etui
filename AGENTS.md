# Project guidance

- Launcher is a dependency-free Swift 6 / AppKit application for macOS 26+; prefer native APIs.
- `Launcher.swift` owns panel lifecycle and input; `Views.swift` owns presentation and the shared panel chrome (`PanelStyle`, `Row`, `GlassPanel`, `keyAction` routing) used by both panels; `Catalog.swift`, `Rank.swift`, and `History.swift` own discovery, matching, and persistence; `Text.swift` owns byte-level string primitives shared by them; `Window.swift` owns frontmost-window tiling; `Switcher.swift` owns switch targets (windows of running apps across Spaces, Google Chrome tabs read through `osascript`, and Combe tabs read through Accessibility), reloaded each time the launcher opens; `Clipboard.swift` and `ClipPanel.swift` own pasteboard capture (history, selection grabs, synthesized copy/paste) and the clip panel; `Translate.swift` owns the translate config, the OpenAI-shaped chat client, and the translator; `TransPanel.swift` owns the translate panel and its geometry.
- Catalog entries are apps from the application folders plus System Settings panes from `/System/Library/ExtensionKit/Extensions` (extension point `com.apple.Settings.extension.ui`); panes open through `x-apple.systempreferences:<bundle id>`.
- Search uses exact, prefix, and word-prefix matching plus learned aliases and usage; preserve the Unicode behavior covered by existing checks.
- User data lives in `~/Library/Application Support/Launcher/{aliases,usage,hidden}.json` plus `clipboard/` (`index.json` and `blobs/`) and `translate.json` (`base`, `key`, `model`, optional `extra` merged into the request body, `styles` with optional per-style `model` and `extra` overrides); use temporary directories for persistence checks.
- Run `make check` for code changes; extend `Tests/LauncherTests/Checks.swift` for uncovered behavior.
- Verify UI changes in the native app, including affected hotkey, focus, dismissal, input-method bypass in the search field, and launch behavior; tests alone do not prove these.
- `make app` packages locally; `make install` replaces `/Applications/Launcher.app`, opens it, and may register a login item, so use it only when installation is requested.
- Keep scratch files and distribution artifacts under `.local/`; use `make dmg` for disk images.
